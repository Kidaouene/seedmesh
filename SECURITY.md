# Politique de sécurité (brouillon — non publiée)

- Version supportée : la branche principale uniquement.
- Signalement : en privé, via GitHub Security Advisories du dépôt (« Report a vulnerability ») une fois le dépôt public. Ne pas ouvrir d'issue publique.
- Délais visés (bénévole, sans garantie) : accusé de réception sous 7 jours, évaluation sous 30 jours, divulgation coordonnée sous 90 jours.
- Hors périmètre connu et documenté : le serveur HTTP du cache n'a PAS d'authentification ; il doit rester sur 127.0.0.1 (voir docs/BOUNTY.md).
- Récompenses : voir docs/BOUNTY.md (enveloppe plafonnée, possiblement symbolique).
